# 📚 Descripción del curso

La asignatura **Desarrollo Fullstack II** tiene como objetivo fortalecer las competencias necesarias para desarrollar aplicaciones web, integrando tecnologías frontend y posteriormente herramientas utilizadas en el desarrollo fullstack.

Durante el curso se trabajarán progresivamente conceptos de:

* Desarrollo web frontend.
* Estructura y diseño de páginas web.
* Programación con JavaScript.
* Manipulación de elementos HTML.
* Organización del código.
* Uso de herramientas modernas de desarrollo.
* Control de versiones utilizando Git y GitHub.

# 💻 Control de versiones

Durante el desarrollo del curso utilizaremos Git y GitHub como herramientas para:

* Guardar versiones del código.
* Registrar avances.
* Revisar cambios realizados.
* Mantener un historial de desarrollo.

Comandos básicos utilizados:

```bash
git add .
```

```bash
git commit -m "Descripción del cambio"
```

```bash
git push
```

Para actualizar una copia local:

```bash
git pull
```
